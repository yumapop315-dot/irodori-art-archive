# 彩りアートアーカイブ

X(旧Twitter)に投稿されたブルーアーカイブのファンアートを、キャラ名タグで検索・閲覧できるサイト。
[要件定義](../要件定義.md) に基づく実装。

- 本番URL: **https://irodori-art-archive.com** （`lib/site.ts` の `SITE_URL` で管理）
- ドメイン取得済み。サーバーは クラウドVPS by GMO（Ubuntu 24.04 / メモリ1GB / root権限あり）。
  デプロイ手順は [デプロイ手順.md](デプロイ手順.md) を参照
- サイト名にブルアカ固有名詞(キヴォトス等)や公式タイトル語を使わないこと（公式誤認・不正競争防止法のリスク回避のため意図的に避けている）

## 起動方法

```bash
npm install
npm run dev
```

http://localhost:3000 で開く。データは `data/app.db`（SQLite）に保存される（初回起動時に自動作成、生徒マスタを自動シード）。

## ページ構成

| URL | 内容 |
|---|---|
| `/` | 一覧（無限スクロール）・チップ式検索・人気タグ・6種ソート |
| `/tag/キャラ名` | キャラ別まとめページ（例: `/tag/ホシノ`。ひらがな・ローマ字でも解決）。複数タグのAND検索は `/?tags=A,B` |
| `/register` | イラスト登録（URL貼付→自動プレビュー→タグ自動サジェスト→登録、一括登録対応） |
| `/students` | キャラ一覧（学園別・投稿数・フォローボタン） |
| `/favorites` | お気に入り一覧（♡したイラスト） |
| `/following` | フォロー中の生徒の新着（ヘッダーのベルに新着バッジ） |
| `/mutes` | ミュートリスト管理 |
| `/terms` | 利用規約・プライバシーポリシー |
| `/removal` | 掲載停止（削除依頼）フォーム |
| `/admin` | 管理画面（パスワードログイン制） |

## 主な機能

### 閲覧
- 画像は登録時に取得したURL・サイズ情報で**自前の軽量カード表示**（埋め込み不使用で高速、レイアウトシフトなし、遅延読み込み）
- 画像クリックでライトボックス（複数枚めくり・キーボード操作対応）
- 無限スクロール、スケルトンローディング
- タグ検索結果ページはタイトル/OGPにキャラ名入り（共有・SEO対応）

### 検索（表記ゆれ対応）
- チップ式タグ入力＋サジェストドロップダウン
- ひらがな（せいあ）・ローマ字（seia）・フルネーム（百合園セイア）・部分一致で解決
- 0件時は「もしかして」候補を提示

### ユーザー機能（ログイン不要・localStorage）
- いいね（人気順ソートに反映）＋お気に入り一覧
- 生徒フォロー＋新着通知バッジ
- 作者ミュート（カードの⋯メニューから）

### 登録
- URL貼り付けで自動プレビュー（600msデバウンス）
- 本文からキャラ名タグを自動サジェスト（かな・別名対応）
- 一括登録（1行1URL、最大10件）
- 重複・画像なし投稿は拒否、IPベースのレート制限あり

### 管理（`/admin`）
- パスワードログイン（httpOnly Cookieセッション、HMAC署名）
- フィルタ（すべて/タグ未設定/消滅）、本文からのタグ候補ワンクリック適用
- 削除依頼の受付・対応管理
- 消えたツイートの検出（画面から実行 or `node scripts/check-dead.mjs` をcronで）
- 生徒マスタ編集（学園・別名）

## 環境変数

`.env.example` を `.env.local` にコピーして設定する。

```bash
# .env.local
ADMIN_KEY=ランダムな長い文字列   # 管理パスワード（デフォルト change-me は必ず変更）

# 広告（Google AdSense、任意）
NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-xxxxxxxxxxxxxxxx
NEXT_PUBLIC_ADSENSE_SLOT_INFEED=xxxxxxxxxx   # インフィード用ディスプレイ広告ユニット
NEXT_PUBLIC_ADSENSE_SLOT_BANNER=xxxxxxxxxx   # ページ下部バナー用ユニット
```

### 広告について

- 表示箇所は「トップ一覧の8件目の後（以降12件ごと）のカード型」と「ページ最下部バナー」の2種のみ。追尾・全画面・ポップアップは使わない方針
- **健全版のみ配信**（きわどい版・R18版ではスクリプトごと読み込まない）。成人向けコンテンツへの配信はAdSenseポリシー違反のため、この制御は外さないこと
- **未設定の間は広告枠ごと非表示**（広告なし運用）。envを設定すると配信が始まる
- 公開時は AdSense の審査に加えて、ドメイン直下に `ads.txt` を配置すること（AdSense管理画面の指示に従う）

## デプロイ時の注意

- SQLiteはファイルDBのため、Vercel等のサーバーレスでは永続化されない。**VPSで動かすか、Supabase(PostgreSQL)等へ移行**すること
- レートリミッタはメモリ内実装。複数プロセス構成にする場合はRedis等へ
- `scripts/check-dead.mjs` を日次cronに登録すると消滅ツイートが自動で非表示になる
- 公開前チェック: ADMIN_KEY変更 / 利用規約の運営者情報記入 / 削除依頼フローの動作確認
